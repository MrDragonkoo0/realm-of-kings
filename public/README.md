# Realm of Kings v0.10.0 — Structure Mode

Temporary development build based on v0.9.9. PNG artwork is preserved in the archive but disabled in the UI so development can focus on game structure and logic. The interface currently uses text/emoji fallbacks.

## Run
- Node.js 18+
- `npm install`
- `npm start`

Keep the existing Railway volume and `DB_PATH` settings. Do not replace the live database with an empty database.

This is a structural UI preparation build; it does not claim that all planned v0.10 economy systems are already implemented.
