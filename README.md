# Realm of Kings v0.9

## Що нового
- Головне меню використовує окремі текстури кнопок у стилі темного середньовічного інтерфейсу із золотими рамками.
- Нижня навігація використовує окремі текстури з перемиканням normal/active.
- У редактор прапора додано 15 деталізованих щитових гербів (усього 44 варіанти емблем).
- Чорний фон щитових гербів і шаховий фон кнопок прибрано там, де це можливо, для використання як прозорих зображень.
- Збережено чинні API та SQLite-схему; зміни БД і міграції не потрібні.
- Пункти Завдання, Дипломатія, Технології, Контракти та Дослідження мають сторінки-заглушки, оскільки їхні ігрові механіки ще не реалізовані.

## Розгортання
1. Розпакуйте архів.
2. Завантажте в GitHub вміст теки `rok05`, замінивши файли проєкту.
3. Залиште Railway Volume підключеним до `/data`, `DB_PATH=/data/rok.db` та приватний `BOT_TOKEN` без змін.
4. Дочекайтеся деплою й перевірте журнал Railway.

Потрібен Node.js >= 22.5.
