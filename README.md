# Realm of Kings — ROK v0.5

ROK v0.5 додає середньовічну систему видобутку ресурсів.
- 🌲 Ліс і лісоруби
- 🪚 Лісопилка
- ⛏️ Шахта
- 👷 Робітники та їх призначення
- 🪨 Камінь і ⛓️ залізо з шахти
- 🚚 Автоматичне надходження добутих ресурсів на склад
- 🗺️ Місця видобутку
- ❌ Ручний збір кнопкою прибрано

SQLite migration is non-destructive. Keep Railway Volume mounted at `/data`, `DB_PATH=/data/rok.db`, and `BOT_TOKEN` unchanged.
