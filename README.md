# Realm of Kings v0.9.1

## Що нового
- Головне меню використовує окремі текстури кнопок у стилі темного середньовічного інтерфейсу із золотими рамками.
- Нижня навігація використовує окремі текстури з перемиканням normal/active.
- У редактор прапора додано 15 деталізованих щитових гербів (усього 44 варіанти емблем).
- Чорний фон щитових гербів і шаховий фон кнопок прибрано там, де це можливо, для використання як прозорих зображень.
- Збережено чинні API та SQLite-схему; зміни БД і міграції не потрібні.
- Пункти Завдання, Дипломатія, Технології, Контракти та Дослідження мають сторінки-заглушки, оскільки їхні ігрові механіки ще не реалізовані.

## Розгортання
1. Розпакуйте архів.
2. Завантажте в GitHub вміст теки `rok05`, замінивши файли проєкту.
3. Залиште Railway Volume підключеним до `/data`, `DB_PATH=/data/rok.db` та приватний `BOT_TOKEN` без змін.
4. Дочекайтеся деплою й перевірте журнал Railway.

Потрібен Node.js >= 22.5.


## v0.9.1 — виправлення інтерфейсу
- Перероблено картки головного меню: іконка й напис тепер окремі HTML-елементи, тому текст не губиться у фоні текстури.
- Нижня навігація має читабельні підписи замість тексту, вбудованого в PNG.
- Зменшено порожні проміжки, налаштовано картки під вузькі екрани.
- Збільшено та вирівняно плитки гербів у редакторі.
- API, сервер і схема SQLite не змінювалися.


## v0.9.3 — текстури інтерфейсу
- Головні 12 карток показують реальні PNG-текстури через явні `img src` та мають стани normal/active/disabled.
- Нижня навігація використовує п’ять наборів текстур, перемикаючи active/normal.
- Усі 28 зображень гербів розташовані без підпапок у `public/heralds/`; код посилається на `/heralds/<id>.png`.
- Фоновий SVG має абсолютний шлях; CSS/JS отримали версію `0.9.3` для очищення кешу.
