# Realm of Kings v0.8

## Що змінилося
- Оновлено головний екран під Telegram Mini App: компактні ресурси, картка королівства, рівень і населення.
- Додано плиткове меню для міст, сіл, війська, казни, населення, ресурсів, ферми, ринку, прапора, оборони, складу та онлайн-світу.
- Додано нижню мобільну навігацію: Головна, Королівство, Мапа, Хроніки, Профіль.
- Додано сторінки профілю та хронік і SVG-пейзаж замку для головної картки.
- Збережено наявні API, логіку гри, редактор прапорів і SQLite-схему.

## Розгортання
1. Розпакуйте архів і завантажте файли з теки `rok05` до репозиторію.
2. У Railway залиште наявні змінні та Volume без змін.
3. Не видаляйте базу даних. `DB_PATH` має залишатися `/data/rok.db`, `BOT_TOKEN` тримайте лише у Variables.

Node.js >= 22.5. Запуск: `npm start`.
