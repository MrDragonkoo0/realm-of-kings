# Realm of Kings — ROK v0.7

## Нове у v0.7
- Додано 13 окремих ілюстрованих гербів: лев, орел, дракон, вовк, олень, ведмідь, кінь, змія, лисиця, грифон, схрещені мечі, бойова сокира та шолом лицаря.
- Герби відображаються у каталозі редактора, у попередньому перегляді прапора, профілі королівства та списку онлайн-світу.
- Решта гербів поки використовують векторні символи; можна поступово замінювати їх окремими ілюстраціями.
- Зображення оптимізовані та розміщені у `public/heralds/`.
- Збереження прапора лишається серверним; база даних і записи гравців не очищуються.

## Розгортання на Railway
1. Розпакуй архів і заміни файли проєкту у GitHub-репозиторії.
2. Залиш `DB_PATH=/data/rok.db` та приватний `BOT_TOKEN` без змін.
3. Не видаляй Railway Volume, змонтований у `/data`, і файл бази даних.
4. Дочекайся deployment та перевір Railway Logs.

Потрібен Node.js >=22.5.0. Запуск: `npm start`.

Примітка: поточний екран «Світ» залишається списком королівств, а не графічною спільною картою.
