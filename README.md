# Realm of Kings — ROK v0.4

ROK v0.4 adds the first 10 core game systems:
1. World
2. City development
3. Villages
4. Agriculture
5. Resources
6. Economy
7. Trade
8. Army
9. Defense
10. Population

The SQLite database is migrated non-destructively. Keep Railway Volume mounted at `/data`, `DB_PATH=/data/rok.db`, and `BOT_TOKEN` unchanged.
